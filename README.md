### AICTE–IBM SkillsBuild Capstone · SDG 4: Quality Education

> **Disclaimer:** AI-generated content (quizzes, study plans, explanations) may contain errors. Always verify with your textbook or teacher.

---

## What it does

EduAgent is an **autonomous AI learning mentor** for STEM students:

1. **Assesses** your knowledge with a diagnostic MCQ quiz
2. **Plans** a personalised day-by-day study roadmap
3. **Curates** real free resources (YouTube, NPTEL, Khan Academy) via DuckDuckGo search
4. **Tracks** your progress and quiz scores across sessions
5. **Nudges** you when you haven't studied in a while

## Quick-start (5 minutes)

### Prerequisites
- Python 3.10 or higher
- A free API key from **Groq** (recommended) _or_ **Google Gemini**

### 1. Get your API key
- **Groq (recommended):** Sign up at [console.groq.com](https://console.groq.com) → API Keys → Create key (free, fast)
- **Gemini:** [aistudio.google.com](https://aistudio.google.com) → Get API key (free tier)

### 2. Clone / download the project

```
cd eduagent/
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Set up environment variables

```bash
# Copy the example file
cp .env.example .env

# Edit .env and paste your API key
```

`.env` file contents:
```
GROQ_API_KEY=gsk_your_key_here
LLM_PROVIDER=groq
```

### 5. Run the app

```bash
streamlit run app.py
```

The app opens at **http://localhost:8501** in your browser.

## Switching LLM providers

Edit `.env`:

```
# For Groq (LLaMA 3.3 70B — fast, free tier)
LLM_PROVIDER=groq
GROQ_API_KEY=gsk_...

# For Gemini (Gemini 1.5 Flash — free tier)
LLM_PROVIDER=gemini
GEMINI_API_KEY=AIza...
```

No code changes needed — `llm.py` handles both.

## Privacy & data notes

- Student names are stored **only in the local SQLite file** — they are never sent to the LLM.
- All LLM calls use the anonymous `student_id` (e.g. `stu_a3f2b1c9`).
- Resource links are found via DuckDuckGo search — not generated by the AI, so they are real URLs.
- No data leaves your machine except the LLM API calls (subject, topic names, quiz prompts).

## Troubleshooting

| Problem | Fix |
|---------|-----|
| `GROQ_API_KEY not set` | Make sure `.env` exists and has the correct key |
| `Quiz generation failed after 3 attempts` | Check your internet connection and API key |
| `streamlit: command not found` | Run `pip install streamlit` and try again |
| Resource search returns no links | DuckDuckGo may rate-limit; wait 30 seconds and retry |
| `ModuleNotFoundError: No module named 'groq'` | Run `pip install -r requirements.txt` again |
